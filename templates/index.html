Project Overview

GridPulse is an AI-driven electricity demand forecasting system that predicts future electricity consumption using Machine Learning and Time-Series Forecasting. The project compares a Naive Baseline, Facebook Prophet, and an Optuna-tuned XGBoost model. Predictions are interpreted using SHAP Explainability, making the model transparent and trustworthy.

Dataset

Daily Telangana Electricity Consumption Data

Feature Engineering

Lag Features, Weekend, Festival, IPL Days, Calendar Features

Machine Learning
